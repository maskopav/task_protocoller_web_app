Design notes. The page has no primary button, because a library entry is created in one place only: a study's Protocols tab, through ⋯ › Share to library. That keeps one way in. Every entry is a copy source, never a live link. "Used in" counts the studies holding a copy. This page and its sidebar item only appear for people who write protocols: master, anyone with can_create_projects, and study editors. A clinician who only receives studies doesn't see it.
