Design notes. Protocols is the default tab. Each row is one logical protocol with its language variants as chips (F-014). Row actions sit in "⋯", so the page has one primary action. Protocols of other studies never appear here (audit A6). Library: "New protocol" offers Blank or From library. Adding always makes a copy, and the copy names its source ("From library: Motor video tasks v2"). "In library" marks a protocol this study has shared. Its author can push a new version with ⋯ › Update library entry, and existing copies stay untouched.
