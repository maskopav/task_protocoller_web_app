Design notes. A workspace instead of a form. The library sits on the left, the protocol at full height in the middle (drag to reorder, so no separate Reorder mode), and settings on the right. Language variants are chips next to the title. Save is the only primary action; it's enabled only when something changed, and the version warning appears only then (audit B3). Boolean defaults read Yes/No (F-007). New protocols start with a required patient code and ${patientCode} in the file name (F-006). For a received study, the same screen has no Save, no library, and a read-only banner.
